# Git Commit & Push Rule

**CRITICAL CONSTRAINT:**
Do NOT commit any changes or push to GitHub until and unless the user explicitly tells you to do so in their message.

- Never run `git commit` automatically after making edits, fixing bugs, or implementing features.
- Never run `git push` automatically.
- Only stage (`git add`), commit (`git commit`), or push (`git push`) when the user explicitly commands it (e.g., "commit this", "push to github", "push into the repo").
